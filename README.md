## Run this project locally

Frontend:

```sh
npm install
npm run dev -- --host 0.0.0.0 --port 8080
```

Backend:

```powershell
.\start-backend.ps1
```

The backend reads its database and JWT settings from `backend/src/main/resources/application.properties`, and every value can be overridden with environment variables like `DATABASE_URL`, `DATABASE_USERNAME`, `DATABASE_PASSWORD`, and `APP_JWT_SECRET`.

### Mobile QR scanning note

Live camera scanning needs `https://` or `localhost`. If you open the app on a phone through an `http://<ip-address>:8080` link, the browser can block camera APIs. The student scan page now includes a `Scan From Photo` fallback so the QR can still be decoded from a captured image. For fully seamless mobile camera scanning, deploy the app over HTTPS.
